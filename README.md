## 🎯 What is GPT-DB?

🤖 **GPT-DB is an open-source AI-native data app development framework** that revolutionizes how you build intelligent applications with **AWEL (Agentic Workflow Expression Language)** and **multi-agent systems**.

### 🌟 Core Mission

> Build the infrastructure for the large model era through advanced technical capabilities including:
> - Multi-model management (SMMF)
> - Text2SQL optimization
> - RAG framework enhancement
> - Multi-Agents collaboration
> - AWEL workflow orchestration

🚀 **In the Data 3.0 era, enterprises and developers can build bespoke applications with minimal code**, leveraging the power of models and databases.

### 💎 Core Capabilities

| Capability | Description | 🚀 Status |
|------------|-------------|-----------|
| **RAG (Retrieval Augmented Generation)** | Build knowledge-based applications with advanced RAG capabilities | ✅ Production Ready |
| **GBI (Generative Business Intelligence)** | Enterprise report analysis and business insights foundation | ✅ Production Ready |
| **Fine-tuning Framework** | Complete fine-tuning framework with 82.5% accuracy on Spider dataset | ✅ Production Ready |
| **Data-Driven Multi-Agents** | Self-evolving multi-agents framework for continuous decision-making | ✅ Production Ready |
| **Data Factory** | Trustworthy knowledge and data processing for the LLM era | ✅ Production Ready |
| **Data Sources Integration** | Seamless connection of production business data | ✅ Production Ready |

## ✨ Key Features

### 🔍 Private Domain Q&A & Data Processing
🔍 **Unlock the Power of Private Domain Knowledge**

GPT-DB enables you to build intelligent knowledge bases with advanced data extraction and unified vector storage capabilities. With our platform, you can:
> Build intelligent knowledge bases with advanced data extraction and unified vector storage capabilities.

- **Multi-format Support** - Upload and process various file formats
- **Custom Plugins** - Integrate custom data extraction pipelines
- **Vector Storage** - Unified vector storage and retrieval for large-scale information management

### 📊 Multi-Data Source & Generative Business Intelligence

> Natural language interaction with diverse data sources for intelligent insights.

- **Universal Connectivity** - Excel, databases, and data warehouses integration
- **Conversational Queries** - Intuitive natural language data exploration
- **Automated Reports** - Generate analytical reports with valuable insights

### 🤖 Multi-Agents & Plugins

> Extensible architecture with custom plugins and Auto-GPT compatibility.

- **Custom Plugins** - Perform various tasks with extensible plugin system
- **Auto-GPT Integration** - Native support for Auto-GPT plugin model
- **Agent Protocol** - Adheres to standard Agent Protocol specifications

### 🔧 Automated Fine-tuning Framework

> Streamlined Text-to-SQL fine-tuning with assembly-line simplicity.

- **LLM-Centric** - Built around large language models
- **Multiple Methods** - Support for LoRA/QLoRA/P-tuning approaches
- **High Performance** - Achieved 82.5% accuracy on Spider dataset
- **[GPT-DB-Hub](https://github.com/khulnasoft-bot/GPT-DB-Hub)** - Dedicated fine-tuning workflow

### 🌐 SMMF (Service-oriented Multi-model Management Framework)

> Comprehensive model support for open-source and API-based LLMs.

**Supported Providers:**
- **Open Source:** LLaMA/LLaMA2, Baichuan, ChatGLM, and many more
- **API Models:** Wenxin, Tongyi, Zhipu, and other commercial models

### � Privacy and Security

> Enterprise-grade security through advanced privacy protection technologies.

- **Privatized Models** - Deploy models in your own environment
- **Proxy Desensitization** - Advanced data protection mechanisms
- **Secure Architecture** - End-to-end security framework
