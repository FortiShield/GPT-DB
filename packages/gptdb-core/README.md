# GPT-DB Core

`gptdb-core` is the foundational package of **GPT-DB**, providing the central components and functionalities that power the entire system. It includes the core data structures, algorithms, and utilities that are essential for the other packages.

## ✨ Features

- **Core Data Structures**: Defines the fundamental data structures used in GPT-DB.
- **Essential Utilities**: A collection of helper functions and utilities.
- **Central Functionality**: Implements the core logic of the GPT-DB system.

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or higher

### Installation

This package is a core dependency of GPT-DB and is automatically installed with the main package.
