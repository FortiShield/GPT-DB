# GPT-DB Ext

`gptdb-ext` is a sub-package of **GPT-DB** that contains various extension modules and utilities. This package provides functionalities that can be used across different GPT-DB services and applications to enhance their capabilities.

## ✨ Features

- **Reusable Utilities**: A collection of helper functions and classes.
- **Extension Modules**: Provides extensions for core GPT-DB functionalities.
- **Cross-Package Compatibility**: Designed to be used across multiple GPT-DB packages.

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or higher
- GPT-DB installed

### Installation

This package is part of the main GPT-DB installation. No separate installation is required if you have already installed GPT-DB.
