# GPT-DB App

`gptdb-app` is a sub-package of **GPT-DB** that provides the main application layer for building and running GPT-DB-powered applications. It ties together the core functionalities, services, and clients to create a cohesive application experience.

## ✨ Features

- **Application Scaffolding**: Provides the structure for building applications on top of GPT-DB.
- **Service Integration**: Integrates various services like serving, sandbox, and extensions.
- **Configuration Management**: Manages application-level configurations.

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or higher
- GPT-DB installed

### Installation

This package is part of the main GPT-DB installation and does not require a separate installation.

### Usage

To run the main application, use the following command:

```bash
python -m gptdb_app.main
```
