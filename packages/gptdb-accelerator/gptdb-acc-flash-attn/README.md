# GPT-DB Accelerator - Flash Attention

`gptdb-acc-flash-attn` is a sub-package of the **GPT-DB Accelerator** that provides a wrapper for the Flash Attention module. This package is designed to accelerate the attention mechanism in transformer models, leading to significant performance improvements.

## ✨ Features

- **Flash Attention Integration**: A high-performance implementation of the attention mechanism.
- **Performance Boost**: Speeds up model training and inference.
- **Seamless Integration**: Easy to integrate with existing GPT-DB models.

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or higher
- GPT-DB and GPT-DB Accelerator installed

### Installation

This package is part of the GPT-DB Accelerator and is installed along with it.
