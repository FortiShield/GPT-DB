# GPT-DB Accelerator - Auto

`gptdb-acc-auto` is a key component of the **GPT-DB Accelerator** that provides automatic hardware and platform compatibility. It aims to simplify the complexity of building and deploying on diverse hardware by offering a consistent interface for core models.

## ✨ Features

- **Automatic Hardware Detection**: Automatically detects and utilizes available hardware for acceleration (e.g., GPUs).
- **Platform Compatibility**: Provides a compatibility layer for different operating systems and platforms.
- **Consistent Interface**: Offers a unified API to abstract away hardware-specific details.

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or higher
- GPT-DB and GPT-DB Accelerator installed

### Installation

This package is part of the GPT-DB Accelerator and is installed along with it.
